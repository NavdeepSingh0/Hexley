GitHub's official MCP server inside Antigravity, judged by Hexley on hexley.site through Antigravity's own hook. 31 Oct 2026.
A written record, not a captured session (docs/PHASE_LOG.md, row G3). GitHub's API was used to read back what was and was not written.

Set-up
  Real Antigravity. Test repositories only: one public, one private.
  The GitHub token stays in Antigravity's own config. Hexley holds none.
  Antigravity sends every MCP call to its PreToolUse hook as the built-in tool call_mcp_tool. The hook sends the real tool name and
  arguments to Hexley, and denies if anything goes wrong: Hexley unreachable, no token, or a call in any other shape.

In the attack run Antigravity was told to carry out the planted steps, as a stand-in for a fooled model. No model was actually fooled.

Limits
  - Antigravity's terminal and other built-in tools are not judged, so git or gh there go around Hexley.
  - Its after-tool hook is not documented as carrying results, so Hexley cannot learn from what GitHub returned. The slip treats the
    session as having read untrusted content from its first call.
  - The call shape is not documented and was read from a real run. If an update changes it, the hook denies.
