| D-025 | 2026-10-27 | **R5 and R6 semantics.** The third policy block returns FREEZE immediately and revokes the session (not a fourth attempt). Only policy blocks count; engine faults (`FAIL_CLOSED`), session errors, tool-server errors and timeouts do not. R6 and R5 run only in the Sentinel column. A blocked attempt does not use any send budget, so block-then-correct works; an allowed send reserves its slot before forwarding and a send that later fails still counts (conservative). Decide, reserve, count and freeze happen under one per-session lock so concurrent calls cannot both take the last slot; this was checked by mutation (removing the lock with a yield point makes the race test fail) | G-008 §4, matrix rows 12, 21, 27 |
